# Признаки ДЗ3

Каждая строка `train.csv` и `test.csv` — пара «запрос — документ» из VK MARCO. Документ — веб-страница с зонами Title (заголовок), Body (текст) и URL. Слова — последовательности букв и цифр в нижнем регистре; «стемм» — основа слова после стеммера Snowball для русского. Статистики коллекции (IDF, частоты слов, средние длины) посчитаны по всем документам-кандидатам ДЗ3.

Значения округлены: длины и счётчики — до двух значащих цифр, остальное — до четырёх.

## Запрос

| Признак | Что это |
|---|---|
| `q_len` | число слов в запросе |
| `q_uniq` | число разных слов |
| `q_idf_sum`, `q_idf_max`, `q_idf_min` | сумма, максимум и минимум IDF слов запроса |
| `q_has_digit` | в запросе есть цифра |
| `q_has_latin` | в запросе есть латиница |
| `q_n_candidates` | число документов-кандидатов у запроса |

## Документ, без учёта запроса

| Признак | Что это |
|---|---|
| `title_len`, `body_len` | длина Title и Body в словах |
| `url_len` | длина URL в символах |
| `url_tokens` | число слов в URL |
| `url_depth` | число частей пути после домена |
| `url_is_root` | URL — главная страница сайта |
| `tld_ru`, `tld_com`, `tld_rf` | домен первого уровня .ru, .com, .рф |
| `domain_docs` | сколько документов этого домена среди кандидатов ДЗ3 |
| `body_cyr_share`, `body_digit_share` | доля кириллических букв и цифр в Body |
| `body_uniq_ratio` | доля разных слов в Body: низкая у текстов с повторами |
| `title_in_body` | доля слов Title, которые есть в Body |

## Совпадение с запросом по зонам

Для каждой зоны `title`, `body`, `url`:

| Признак | Что это |
|---|---|
| `bm25_<зона>` | BM25 по зоне, k1 = 1.2, b = 0.75 (у URL b = 0) |
| `tf_sum_<зона>` | сколько раз слова запроса встречаются в зоне |
| `coverage_<зона>` | доля слов запроса, которые есть в зоне |
| `idf_coverage_<зона>` | то же, но слова взвешены по IDF |

И ещё:

| Признак | Что это |
|---|---|
| `lm_title`, `lm_body` | логарифм правдоподобия запроса в языковой модели зоны со сглаживанием Дирихле |
| `bm25f` | BM25F по Title, Body и URL |
| `bm25_stem_title`, `bm25_stem_body` | BM25 по стеммам |
| `coverage_stem_title`, `coverage_stem_body` | доля стеммов запроса в зоне |
| `body_min_window` | длина минимального окна в Body со всеми найденными словами запроса, делённая на их число; −1, если найдено меньше двух слов |
| `body_first_pos` | позиция первого слова запроса в Body; −1, если слов нет |
| `body_matched_first50` | доля слов запроса среди первых 50 слов Body |
| `phrase_title`, `phrase_body` | запрос целиком, подряд, встречается в зоне |
| `title_trigram_jaccard` | сходство запроса и Title по буквенным триграммам |
| `title_starts_with_query` | Title начинается с запроса |
| `query_words_in_domain` | доля слов запроса, которые есть в домене |
| `query_translit_in_url` | доля русских слов запроса, которые в транслитерации есть в URL |

## Домен

| Признак | Что это |
|---|---|
| `domain_prior` | средняя оценка документов этого домена в train, сглаженная к общему среднему. Для строк train посчитана out-of-fold по запросам, чтобы не подсматривать в собственную оценку |
| `domain_train_pairs` | сколько пар с этим доменом в train |

## Внутри запроса

Для `bm25f`, `bm25_title`, `bm25_body`, `coverage_body`, `lm_body`:

| Признак | Что это |
|---|---|
| `<признак>_rank` | ранг документа по признаку среди кандидатов запроса, от 0 до 1 (меньше — выше) |
| `<признак>_to_max` | значение, делённое на максимум по запросу |
| `<признак>_minus_mean` | значение минус среднее по запросу |
